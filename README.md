# Lugg AI Assistant — Fabric мод для Minecraft 1.20.1
## ИИ-помощник с поддержкой OpenRouter, перебирает 35 бесплатных моделей автоматически!

Нажимаешь **J** в игре → открывается меню с 6 кнопками, пишешь что нужно и ИИ отвечает прямо в игре.
Не нужно запускать никаких локальных серверов — мод отправляет запрос напрямую в OpenRouter.

### 6 доступных функций ИИ:
| Кнопка | Что умеет |
|--------|-----------|
| 🏗 Построить | ИИ придумывает и пошагово описывает любую постройку |
| 🎬 Катсцена | Придумывает полный сценарий катсцены с диалогами и камерой |
| 🗡 Предмет/блок/моб | Описывает новый контент, может выдать готовый Java-код |
| 💡 Идея | Придумывает квесты, сценарии выживания, необычные идеи |
| 🔊 Озвучить | Готовит текст для озвучки дикторским голосом |
| ⚙ Любой механизм | Детальные пошаговые инструкции даже для самых сложных редстоун-механизмов и ферм |

## 📝 ПОЛНАЯ ИНСТРУКЦИЯ КАК ПОЛУЧИТЬ API КЛЮЧ OPENROUTER БЕСПЛАТНО:

### Шаг 1. Регистрация
1. Открой в браузере сайт: **https://openrouter.ai/**
2. Нажми кнопку `Sign In` в правом верхнем углу
3. Зарегистрируйся любым удобным способом: через Google, GitHub, Discord, Apple или почту.
   ❗ **Регистрация полностью бесплатная, карта не нужна.**

### Шаг 2. Создаем API ключ
1. После входа открой страницу ключей: **https://openrouter.ai/keys**
2. Нажми оранжевую кнопку **`Create Key`**
3. Введи любое название для ключа, например `minecraft-lugg`
4. Остальные настройки оставь по умолчанию, нажми `Create`
5. Ты увидишь ключ который выглядит так: `sk-or-v1-abcdef1234567890.....` — **скопируй его целиком**
   ❗ Ключ показывается только один раз, не закрывай страницу пока не скопируешь!

### Шаг 3. Бесплатные модели (баланс пополнять НЕ НУЖНО!)
На OpenRouter есть огромное количество полностью бесплатных моделей (с лимитами на количество запросов в минуту/день).
**Мод автоматически перебирает 35 бесплатных моделей по очереди**:
- Если одна перегружена/закончился лимит/не отвечает — моментально пробует следующую
- Тебе не нужно ничего настраивать, просто отправляй запрос
- Пополнять счет на OpenRouter НЕ ТРЕБУЕТСЯ

Список всех бесплатных моделей которые использует мод:
Gemma 2 (9b/27b), Gemma 3 (4b/12b/27b), LearnLM, Llama 3.1 (8b), Llama 3.2 (1b/3b), Llama 3.3 70b, Llama 4 Maverick/Scout, Mistral 7b/Nemo/Small, Qwen 2/2.5/3 (до 72b параметров!), DeepSeek V3/R1, Hermes 3, Dolphin 3, Rogue Rose 103b, Kimi K2 и другие.

### Шаг 4. Вводим ключ в моде
1. Запусти Minecraft с установленным модом
2. Нажми клавишу **J**, чтобы открыть меню ИИ
3. Нажми кнопку **⚙ Настройки (API ключ OpenRouter)**
4. Вставь скопированный ключ в поле ввода
5. Нажми **💾 Сохранить ключ**

✅ Ключ сохраняется в конфиге `config/lugg_ai.json` и больше не потребуется вводить.

### Шаг 5. Пользуемся!
1. Вернись в главное меню ИИ нажатием кнопки `← Назад`
2. Выбери любую из 6 функций
3. Напиши в поле то что нужно сделать, например: `построй средневековый замок на 15x15 блоков`
4. Нажми **Отправить запрос ИИ** (или просто Enter)
5. Подожди несколько секунд — мод перебирает бесплатные модели и показывает ответ прямо в игре.
   Можно прокручивать ответ колесиком мыши!

## 🚀 КАК СРАЗУ СОБРАТЬ МОД НА СВОЕМ КОМПЬЮТЕРЕ (ОДИН КЛИК!):

### 🪟 Для Windows:
1. Установи **Java 17 JDK** (только один раз, обязательное требование Minecraft 1.20.1):
   - Скачай бесплатно: https://adoptium.net/temurin/releases/?version=17&package=jdk&os=windows
   - Запусти установщик, на всех шагах жми Далее (ничего менять не нужно)
   - ❗ **ПЕРЕЗАПУСТИ КОМАНДНУЮ СТРОКУ ПОСЛЕ УСТАНОВКИ JAVA**
2. Скачай или склонируй этот репозиторий себе на компьютер
3. **Двойной клик по файлу `build_windows.bat` — всё!**
   - Батник автоматически проверит Java
   - Сам скачает недостающий `gradle-wrapper.jar` (пробует PowerShell, потом curl)
   - Сам запустит сборку мода
4. После успешной сборки готовый мод лежит в папке `build/libs/lugg-1.2.0-openrouter.jar`

Если появляется ошибка `Could not find or load main class org.gradle.wrapper.GradleWrapperMain` — это именно значит что не скачался файл `gradle/wrapper/gradle-wrapper.jar`. Запусти `build_windows.bat` ещё раз или скачай его вручную в браузере по этой ссылке и положи в папку `gradle/wrapper/`:
https://raw.githubusercontent.com/gradle/gradle/v8.5.0/gradle/wrapper/gradle-wrapper.jar

### 🐧🍎 Для Linux/macOS:
```bash
cd путь/к/папке/мода
chmod +x build_linux_mac.sh
./build_linux_mac.sh
```
Скрипт сделает всё автоматически.

## Структура кода:
```
src/main/java/com/lugg/mod/
├── LuggMod.java                   # Точка входа
├── LuggModClient.java             # Клиентская инициализация
├── config/
│   └── ModConfig.java             # Сохранение/загрузка API ключа в конфиг
├── ai/
│   ├── OpenRouterClient.java      # HTTP клиент с автоматическим перебором моделей
│   └── OpenRouterModels.java      # Список 35 бесплатных моделей и системные промпты
└── client/
    ├── input/
    │   └── KeyBindings.java       # Клавиша J для открытия меню
    └── screen/
        ├── AIMenuScreen.java      # Главное меню из 6 кнопок + кнопка настроек
        ├── AIRequestScreen.java   # Экран запроса, статус и прокручиваемый ответ
        └── SettingsScreen.java    # Экран ввода и сохранения API ключа с инструкцией
```

## Частые проблемы:
- ❌ `Все модели не ответили`: проверь интернет, убедись что ключ не содержит лишних пробелов, попробуй через пару минут.
- ❌ Ошибка авторизации: пересоздай ключ на openrouter.ai/keys и сохрани его заново в настройках.
- Медленный ответ: бесплатные модели иногда загружены, мод автоматически пробует быстрые модели сначала.
